# VOIS_AICTE_Oct2025_Anjali

## 📊 Airbnb Hotel Booking Analysis: New York City Market Dynamics

This repository holds the project for the **Edunet Foundation X VOIS** virtual internship program, demonstrating core data analysis skills in Python.

### 🎯 Project Overview

The goal of this project was to conduct a comprehensive Exploratory Data Analysis (EDA) on the New York City Airbnb dataset to uncover actionable insights on the short-term rental market.

The analysis included:

* Data cleaning and type conversion.
* Geographical distribution and listing count analysis.
* Examination of pricing trends (price vs. construction year).
* Correlation studies (Price vs. Service Fee).
* Host performance and guest review analysis.

### 🛠️ Technology Stack

* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Deliverable:** Jupyter Notebook (`.ipynb` file)
